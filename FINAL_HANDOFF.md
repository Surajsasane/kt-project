## 📞 **EMERGENCY CONTACTS** (Troubleshooting)

**If backend won't start:**
```bash
# Kill old process
taskkill /F /IM node.exe
# Restart
node server.js
```

**If frontend won't start:**
```bash
# Delete cache
rm -rf node_modules
npm install
npm run dev
```

**If database is corrupt:**
```bash
# Delete and recreate
rm backend/database.db
# Restart server - auto-creates
```
