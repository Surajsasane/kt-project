Place your company logo image here so the app shows it on the login screen.

Save the image with the filename: logo.png

Path: frontend/public/logo.png

When running the Vite dev server, files in the `public` folder are served at the root.
Example URL in browser/devtools: http://localhost:5173/logo.png

Alternative: if you prefer the backend to serve the image, upload it to `backend/uploads` and use `/uploads/<filename>` as the image URL in the app.
